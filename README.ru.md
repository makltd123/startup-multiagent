# Мультиагентная система для стартапа

[English](README.md) | **Русский**

Консольная «команда» из LLM-агентов для основателя стартапа, работающего в одиночку. Вы в роли CEO даёте задачу; оркестратор разбивает её на граф подзадач, профильные агенты выполняют их — где можно, параллельно, — и вы получаете один сводный отчёт. Без агентных фреймворков: только `httpx` и `asyncio` поверх бесплатных эндпоинтов NVIDIA NIM.

## Как это работает

```
задача ──► Оркестратор: план в виде JSON-графа подзадач
             ──► агенты работают уровень за уровнем: внутри уровня параллельно,
                 ранние результаты передаются дальше через context_keys
             ──► Оркестратор: сводный отчёт
             ──► проверка Guard ──► отчёт (сохраняется в logs/)
```

| Роль | Модель (NVIDIA NIM) | Запасная | Задача |
|---|---|---|---|
| Оркестратор | `deepseek-ai/deepseek-v3.1-terminus` | `deepseek-v3.2` | строит граф, пишет итоговый отчёт |
| Researcher | `moonshotai/kimi-k2-instruct-0905` | `deepseek-v3.2` | рынок, конкуренты, портрет клиента; сначала получает результаты DuckDuckGo |
| CTO | `qwen/qwen3-coder-480b-a35b-instruct` | `devstral-2-123b` | стек, архитектура MVP, оценка трудозатрат |
| Product | `mistralai/mistral-large-3-675b-instruct-2512` | `kimi-k2-thinking` | PRD, user stories, роадмап |
| Marketing | `mistralai/mistral-nemotron` | `mistral-large-3` | позиционирование, выход на рынок, контент |
| Sales | `mistralai/mistral-large-3-675b-instruct-2512` | `kimi-k2-instruct` | цепочки холодных писем, скрипты разговоров, воронка |
| Guard | `nvidia/llama-3.1-nemotron-safety-guard-8b-v3` | `llama-guard-4-12b` | проверяет итоговый отчёт |

Каждый результат агента также сохраняется в память: хранилище ключ-значение (`memory/context.json`) и хранилище эмбеддингов (`memory/embeddings.json`, модель `llama-3.2-nemoretriever-300m-embed-v1`). В интерактивном режиме `recall: <вопрос>` ищет по смыслу среди результатов текущей сессии, а планировщик видит краткую историю прошлых запусков и может не повторять работу, которая ещё актуальна.

## Запуск

```bash
pip install -r requirements.txt
echo NVIDIA_API_KEY=nvapi-... > .env     # бесплатный ключ на build.nvidia.com

python main.py "Проанализируй рынок B2B HR-автоматизации и сделай план MVP"
python main.py --interactive
```

Команды интерактивного режима: любой текст задачи, `recall: <вопрос>`, `history`, `quit`.

## Ограничения

- **Guard — это фильтр безопасности, а не ревьюер.** В промпте он должен проверять фактическую непротиворечивость и полноту, но обе модели — классификаторы безопасности, которые отвечают «safe» / «unsafe» с категорией. Поэтому отмечается только небезопасный контент.
- План разбирается из JSON-ответа модели (обёртки markdown срезаются), поэтому необычный формат ответа ломает запуск.
- У бесплатных эндпоинтов NVIDIA NIM есть лимиты (ошибка 429 повторяется с паузой), а набор доступных моделей со временем меняется.
- История запусков, которую видит планировщик, живёт только в памяти процесса. Файлы памяти сохраняются между запусками, но `recall` ищет только в текущей сессии.
